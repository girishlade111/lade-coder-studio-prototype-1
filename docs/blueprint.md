# **App Name**: Lade Coder

## Core Features:

- Landing Page: Landing page with centered prompt bar and placeholder text.
- Code Preview: Display code in a 'Code' tab and website preview in a 'Live Preview' tab.
- Website Generation: Use the prompt to build a website using HTML, CSS and Javascript.
- Device Preview: Provide device view toggles: desktop, mobile, tablet.
- Export Code: Export the current version of the generated code.
- AI Suggestions: Based on the prompt, provide AI suggestions for improvements.

## Style Guidelines:

- Primary color: Saturated blue (#4285F4) to evoke trust and innovation, in line with a SaaS product for developers.
- Background color: Light gray (#F5F5F5), provides a clean and neutral backdrop that ensures readability and focuses user attention on the key UI elements, following a light color scheme.
- Accent color: Orange (#FF5733), stands out and brings attention to important interactive elements such as call-to-action buttons, adhering to analogous color principles.
- Font: 'Inter' (sans-serif) for both headlines and body text, providing a modern and neutral look for UI elements.
- Use minimalist icons only for buttons to avoid labels
- Emphasize a clean, empty landing page to streamline UI focus
- Animate prompt bar to left sidebar upon submission.
